# Интерфейс shadcn/ui

## Компоненты и тема

shadcn/ui подключён официальным CLI 4.23.0 к существующему Vite-проекту: `init --preset nova --base radix`, затем `add`. Настройка соответствует [инструкции для Vite](https://ui.shadcn.com/docs/installation/vite) и [документации темы](https://ui.shadcn.com/docs/theming). Конфигурация находится в `components.json`.

Обе страницы используют Button, Input, Label, Select, Switch, Tabs, Card, Dialog, Alert, Progress, Badge, Separator и Table; уведомления разработчика — Sonner. Неиспользуемые компоненты, добавленные CLI, и зависимость `next-themes` удалены. `AppBrand` общий для двух шапок; `DeveloperUI` связывает повторяющиеся элементы разработчика с его состоянием.

- `src/theme.css` — палитра, шрифт и радиусы. Значения OKLCH имеют нулевую цветность, включая `destructive`, `ring`, наведение и выбранные элементы. Основная тема светлая. Geist поставляется локально вместе с приложением.
- `src/styles.css` — общая раскладка, типографика, фокус, панели, диалоги и адаптивность.
- `src/viewer.css` — раскладка пользовательской страницы.
- `src/components/ui/` — исходники компонентов shadcn/ui. В Progress исправлена передача значения и максимума в Radix; неопределённый прогресс не объявляет ложный ноль. Области таблиц доступны с клавиатуры.

В `theme.css` явно указан `@source "./"`: HTML-корень Vite находится в `frontend/`, а компоненты — в `src/`. Без этого Tailwind не включал их классы в production CSS.

Тематические цвета карты и точек данных не являются цветами оболочки. Их пороги, легенды и подложка Яндекса сохранены. Глобальный фильтр обесцвечивания к карте не применяется.

## Управление состоянием

React управляет элементами обеих страниц. Координаторы разработчика публикуют значения полей, структурированные данные и команды через `developer-ui-store.js`; они больше не ищут элементы страницы и не записывают HTML. Карточка организации, диалоги, вкладки, формы, прогресс и уведомления рендерятся React. Загрузка SDK, геометрия, расчёт, Worker, хранение и скачивание файлов остаются специализированными модулями.

Импорт копий защищён от позднего завершения старого чтения. Режим объединения или замены фиксируется при запуске восстановления; перед заменой сохраняется предыдущая версия. Закрытие диалога возвращает фокус открывшему элементу; если он скрыт после подключения карты, используется видимая кнопка панели. Ошибки копий и подключения имеют текст, монохромную иконку и границу.

Если пользователь открыл таблицу до готовности SDK, карта один раз подбирает масштаб после возвращения на видимую вкладку. Последующие переходы сохраняют масштаб и положение.

## Обновление интерфейса

Для изменения общей палитры редактируйте токены `src/theme.css`, для раскладки — `src/styles.css` и `src/viewer.css`. После изменений выполните `npm run typecheck`, `npm test` и `npm run build`. Проверки совместимости описаны в [verification.md](verification.md); запуск готовой поставки — в [DEVELOPER.md](DEVELOPER.md).
