# Готовая статическая сборка

Эта папка создаётся командой `npm run build` из корня проекта. Для изменения приложения редактируйте `src/`, `frontend/` и `public/`, затем пересоберите поставку.

Для запуска готового приложения откройте `START.cmd` в корне распакованной поставки. Node.js и npm не нужны. Подробные инструкции: `../README.md` и `../docs/DEVELOPER.md`.
